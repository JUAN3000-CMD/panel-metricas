# 📊 Panel de Control y Métricas Pro (v4.2.0)

Consola inteligente de monitorización académica y rendimiento personal con motor NLP nativo 100 % autónomo, memoria temporal evolutiva, sistema Pomodoro integrado y verificación de integridad criptográfica. Gratuito, sin suscripciones y bajo **Licencia MIT**

---

## 🚀 Modalidades de Uso

Este proyecto está diseñado para adaptarse a cualquier entorno con un único código base:

- **🌐 Versión Web (Siempre actualizada):** Accede directamente desde el navegador de tu ordenador o móvil a través de [GitHub Pages / Repositorio](https://github.com/JUAN3000-CMD/panel-metricas). Se actualiza automáticamente y cuenta con detección de versiones remota mediante manifiesto JSON[cite: 10].
- **💻 Versión Local / Offline (Navegador sin conexión):** Abre el archivo HTML directamente en tu navegador —incluso sin conexión a internet— con tipografías nativas del sistema y motor NLP local sin depender de CDNs externos de librerías o fuentes[cite: 10]. *(El paquete ejecutable de escritorio en Releases sigue en desarrollo).*
- **🛠️ Código Fuente (Educativo):** Clona o descarga este repositorio para estudiar su funcionamiento, modificarlo o adaptarlo a tus necesidades bajo los términos de la **Licencia MIT**[cite: 10].

---

## ✨ Características Principales

- **Gestión Dinámica de Categorías y Ponderaciones:** Crea tus propias asignaturas o áreas, añade calificaciones parciales con pesos configurables (`x1`, `x2`, `x3`) y visualiza el promedio ponderado en tiempo real[cite: 10].
- **🧠 Asistente Pro NLP Local (100 % autónomo):**
  - Motor NLP nativo en JavaScript puro y similitud del coseno ejecutados íntegramente en tu navegador, sin dependencias externas de librerías ni envío de datos a terceros[cite: 10].
  - **Memoria Evolutiva (4 meses):** Pídele que recuerde fechas o datos (*"recuerda que el examen es el viernes"*)[cite: 10]. Los recuerdos se mantienen activos durante 120 días y luego pasan automáticamente a referencia histórica compacta[cite: 10].
  - Resúmenes extractivos locales de temas/apuntes (con adjuntos `.txt`/`.md`/`.csv` o texto pegado), organizador de tareas, generador de planes de estudio por días, simulador de impacto de notas, consejos y modo **No Molestar (DND)**[cite: 10].
- **⏱️ Temporizador Pomodoro Configurable:** Ciclos de estudio, descanso corto y descanso largo personalizables mediante modal con avisos integrados[cite: 10].
- **📅 Agenda y Calendario:** Registro ordenado de exámenes, entregas y tareas pendientes[cite: 10].
- **📊 Visualización, Informes y Resúmenes (PDF / TXT):** Gráficas comparativas por categoría, evolución histórica, emisión de informe con valoración automática opcional y descarga de resúmenes/planes en **PDF** o `.txt`[cite: 10].
- **🔒 Copias de Seguridad Firmadas (SHA-256):** Exportación e importación de datos en formato `.json` con firma digital de integridad (`Web Crypto API`) para detectar archivos corruptos o manipulados[cite: 10].
- **📱 Diseño Adaptable (Responsive) y Modo Oscuro:** Interfaz optimizada para escritorio, tablets y móviles con cierre rápido mediante `Esc` o clic exterior[cite: 10].

## 📖 Guía Rápida

1. **Configura tus categorías:** Pulsa en *⚙️ Gestionar Categorías* para añadir el código y nombre de tus asignaturas o métricas[cite: 10].
2. **Define tus metas:** Ajusta el *Umbral Objetivo* y la *Meta de Categorías* desde las tarjetas superiores mediante sus ventanas modales[cite: 10].
3. **Guarda tus avances:** Los datos se conservan en el almacenamiento local del navegador (`localStorage`) —con guardado preventivo al cerrar la pestaña—, y puedes pulsar *💾 Exportar* para descargar una copia de seguridad en `.json` firmada con SHA-256[cite: 10].
